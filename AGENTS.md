Work efficiently without sacrificing correctness.

- Begin work immediately when the task is clear.
- Ask questions only when missing information materially affects the solution.
- Start with targeted searches and the smallest relevant file set.
- Expand investigation only when imports, callers, tests, or runtime evidence require it.
- Make the smallest coherent change that fully solves the task.
- Avoid unrelated refactoring, formatting, dependency changes, or cleanup.
- Prefer focused patches over full-file rewrites.
- Preserve unrelated working-tree changes.
- Run the narrowest meaningful validation first.
- Do not repeat file contents, logs, or explanations unnecessarily.
- Keep final responses brief: summarize changes, files modified, validation, and remaining risks.
